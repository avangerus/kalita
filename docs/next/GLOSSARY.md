# Словарь N1

**Статус:** общие значения терминов для [HLD](HLD.md), LLD и pack; точные wire types определяются версией контракта.

| Термин | Значение и важное отличие |
|---|---|
| Company / tenant | Граница данных и issuer политики; в первом профиле одна компания на deployment |
| Actor | Аутентифицированный субъект действия; не совпадает автоматически с credential или ответственным человеком |
| AgentProfile | Назначение и допустимые способы работы агента; профиль сам не выдаёт права |
| ResponsibleParty | Человек/роль, принимающий ответственность за область результата |
| Goal | Желаемый исход; изменение цели требует явного решения, а не переписывания старого Run |
| WorkCase | Устойчивая работа с владельцем и ожидаемым результатом, независимо от чата и UI |
| Obligation | Подтверждённое обещание с условиями, стороной и ответственным; извлечение создаёт только candidate |
| Responsibility | Принятое владение работой; в простом кейсе поле owner, при передаче — отдельный контракт |
| Observation | Что и когда получено из конкретного канала, с версией и ограничением полноты |
| Claim | Чьё-то утверждение/интерпретация, включая вывод модели |
| Evidence | Материал, предъявленный для проверки; наличие/хеш не доказывает истинность |
| Acceptance | Решение полномочной стороны по версионированным критериям |
| Outcome | Наблюдаемый итог; causal business benefit проверяется отдельным методом |
| basis | Типизированные ссылки на основания с версиями и ACL, не переносимые bearer permissions |
| ResponsibilityContract | Версионированная область работы, цель, критерии, владелец, пределы и handoff/stop; не credential |
| ExecutionPlanRevision | Изменяемый ограниченный граф способов выполнения в ResponsibilityContract; не изменение цели/grant |
| Run | Конкретное исполнение по закреплённым версиям и выданной области полномочий |
| Step | Ограниченная единица исполнения с input/output/action contract |
| Attempt | Одна попытка Step; имеет lease, fence, лимиты и отдельный исход |
| Grant | Решение issuer о разрешённых действиях/данных/пределах; профиль или prompt не заменяет grant |
| Capability | Короткоживущий серверный handle для конкретного вызова; требует текущей проверки grant |
| Broker | Доверенная граница вызовов моделей, инструментов, контекста и внешних эффектов |
| Effect | Долговечное намерение и состояние внешнего действия; `unknown` не равно failed |
| Receipt | Подтверждение ответа/статуса удалённого действия с ограничениями источника |
| Reservation | Удержанный предел расхода; settlement переводит в списание/освобождение ровно один раз |
| SourceBinding | Версионированная привязка конкретного источника, credential ref, mapping, ACL и freshness |
| Authority | Кто вправе принимать изменение и где первичная запись; отличается от источника прочитанной копии |
| ViewSpec | Проверяемая декларативная композиция компонентов/данных/действий для аудитории |
| Ephemeral view | Временное представление с ограниченным сроком/контекстом |
| Pinned live view | Сохранённый запрос/композиция, показывающая текущие разрешённые данные |
| Shared view | Публикация для указанной аудитории с новой проверкой контента и прав |
| Snapshot | Отдельная фиксированная копия с собственными доступом/retention; экспорт уже нельзя отозвать |
| MethodRevision | Версия метода с владельцем, применимостью, проверками, сроком и отзывом |
| Starter pack | Поддерживаемый процесс + контракты + интеграции + views + политики + установка + проверки |
| R0–R7 | Release milestones плана, не risk classes и не опубликованные версии |
| risk R0–R3 | Классы риска действия в LLD безопасности; в планах пишется `risk class`, чтобы не путать с release |
| I00–I15 | Ограниченные итерации с входом/выходом; duration определяется после декомпозиции |

`definition_version`, `schema_version`, `policy_revision`, `method_revision`, версия API и revision записи различаются. Совпадение номера не означает совместимость. Простая работа не обязана создавать объект каждого типа из этого словаря.
